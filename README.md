Web-based road condition management and visualization system developed during a Praktik Kerja Lapangan (PKL) at Dinas Bina Marga dan Bina Konstruksi (BMBK) Provinsi Lampung.

The system is designed to manage, visualize, and report provincial road condition data using GIS, strip maps, charts, and structured road records.

## Features

* Road section and STA data management
* Road condition classification and visualization
* Interactive GIS map
* Strip map visualization
* KML/KMZ import and coordinate processing
* Excel data import
* Road condition charts and statistics
* Road documentation and photo management
* Recapitulation by road section, district/city, corridor, and UPTD
* Report generation and printing
* Authentication and input validation

## Project Structure

```text
app/
config/
database/
public/
resources/
routes/
```

The application follows an MVC-based architecture to separate application logic, data access, routing, and presentation.

## Project Context

**Project:** BMBK Stripmap
**Institution:** Dinas Bina Marga dan Bina Konstruksi Provinsi Lampung
**Program:** Praktik Kerja Lapangan (PKL)
**Role:** Full-stack Developer

The project was developed to support the management and visualization of road condition data and to improve the efficiency of data processing and reporting.
